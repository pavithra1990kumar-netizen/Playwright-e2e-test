2. difference between html element and html tags

An HTML element is the complete building block of a webpage, consisting of an opening tag, the content, and a closing tag. In contrast, an HTML tag is just the individual marker (like <p> or </p>) used to signal where an element begins and ends.

3. what is element selector

The CSS element selector selects all elements with the specified element name.

This selector can be name spaced when using @namespace.

ns|p - selects <p> elements in namespace ns
*|p - selects all <p> elements
|p - selects all <p> elements without any namespace declared
